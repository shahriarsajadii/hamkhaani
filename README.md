# ربات همخوانی تلگرام 📖

ربات مدیریت گروه‌های هم‌خوانی کتاب با پشتیبانی کامل از تاپیک‌ها (Forum Topics).

## ساختار پروژه

```
readalong_bot/
├── bot.py                  # نقطه ورود اصلی، اجرا کن: python bot.py
├── config.py                # تنظیمات: توکن، آیدی ادمین‌ها، ساعت یادآوری
├── database.py               # لایه دیتابیس (sqlite)
├── scheduler.py               # جاب روزانه‌ی یادآوری خودکار
├── requirements.txt
├── utils/
│   ├── jalali.py             # تبدیل و فرمت تاریخ شمسی
│   ├── keyboards.py          # کیبوردهای شیشه‌ای و منو
│   └── formatting.py          # ساخت متن اعلان‌ها و گزارش‌ها
└── handlers/
    ├── common.py             # /start, /cancel
    ├── admin/                 # مسیرهای پنل ادمین
    │   ├── book.py            # ساخت کتاب، اتصال تاپیک، فعال‌سازی
    │   ├── schedule.py         # تعیین برنامه روزهای همخوانی
    │   ├── questions.py        # تعیین سوالات کتاب
    │   └── reports.py          # گزارش روز / گزارش سوالات / لیست کتاب‌ها
    └── user/                   # مسیرهای پنل کاربر
        ├── registration.py     # ثبت‌نام در کتاب
        ├── tracking.py         # گزارش روزانه (دستی و خودکار)
        └── answers.py          # پاسخ به سوالات کتاب
```

## نصب

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## تنظیمات (config.py یا Environment Variables)

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از @BotFather |
| `ADMIN_IDS` | آیدی عددی تلگرام ادمین‌ها، با کاما جدا شده مثل `111,222` |
| `DAILY_REMINDER_TIME` | ساعت ارسال یادآوری روزانه، مثلا `09:00` |
| `TIMEZONE` | پیش‌فرض `Asia/Tehran` |

می‌تونید مستقیم این مقادیر رو داخل `config.py` هم بنویسید.

اجرا:
```bash
export BOT_TOKEN="123456:ABC..."
export ADMIN_IDS="111111111"
python3 bot.py
```

## نحوه استفاده

### گام صفر — گروه را آماده کنید
1. ربات را به گروه (که Topics/Forum روش فعاله) اضافه کنید و **ادمین گروه** کنید (باید بتونه پیام بفرسته و در تاپیک‌ها هم پیام بده).
2. برای هر کتاب، سه تاپیک بسازید: «پیگیری»، «بریده‌ها»، «گپ».

### گام ۱ — ساخت کتاب (فقط ادمین، در چت خصوصی با ربات)
از منو «➕ کتاب جدید» را بزنید و عنوان، نویسنده، توضیحات را وارد کنید. ربات یک شناسه کتاب (`book_id`) می‌دهد.

### گام ۲ — اتصال تاپیک‌ها
داخل **خودِ گروه**، در هر تاپیک، دستور زیر را بفرستید (ربات باید عضو گروه باشد):

```
در تاپیک «پیگیری»: /settopic <book_id> pigiri
در تاپیک «بریده‌ها»: /settopic <book_id> boride
در تاپیک «گپ»:      /settopic <book_id> gap
```

### گام ۳ — تعیین برنامه همخوانی
از منو «📅 تعیین برنامه همخوانی» را بزنید، کتاب را انتخاب کنید، و به ترتیب برای هر روز:
- تاریخ شمسی (فرمت: `1403/06/21`)
- بازه صفحات کتاب (مثال: `1 تا 30`)
- بازه صفحات پی‌دی‌اف (مثال: `3 تا 15`)

را وارد کنید. بعد از هر روز می‌توانید «➕ افزودن روز بعد» یا «✅ پایان و پیش‌نمایش» را بزنید.

### گام ۴ — فعال‌سازی کتاب
از منو «🚀 فعال‌سازی کتاب» را بزنید. ربات پیام اعلان کامل (دقیقاً مثل فرمتی که خواستید) را در تاپیک «گپ» پست می‌کند و کتاب را «فعال» می‌کند.

### گام ۵ — ثبت‌نام کاربران
کاربران در چت خصوصی با ربات، `/start` می‌زنند، «📚 کتاب‌های فعال» را باز می‌کنند و کتاب موردنظر را انتخاب می‌کنند. آیدی عددی تلگرام آن‌ها خودکار در دیتابیس ذخیره می‌شود.

### گام ۶ — پیگیری روزانه
- **خودکار**: هر روز در ساعت تنظیم‌شده (`DAILY_REMINDER_TIME`)، ربات برای هر کاربرِ ثبت‌نامی، پیام خصوصی با دکمه‌های «بله خوندم / نه هنوز» می‌فرستد.
- **دستی**: کاربر هر وقت بخواهد می‌تواند «✅ گزارش امروز» را از منو بزند.

پاسخ کاربر هم در دیتابیس ذخیره می‌شود و هم به‌صورت خودکار در تاپیک «پیگیری» گروه گزارش داده می‌شود، مثلاً:

```
21 شهریور - محمد این بخش رو خوند.✅
```

### گام ۷ — گزارش‌گیری ادمین
- «📊 گزارش روز»: کتاب و روز مورد نظر را انتخاب کنید تا لیست کامل خوانده‌ها/نخوانده‌ها را ببینید.
- «📋 گزارش سوالات»: کتاب و سوال مورد نظر را انتخاب کنید تا همه پاسخ‌های کاربران به آن سوال، به‌صورت شماره‌گذاری‌شده (مثل نمونه‌ای که فرستادید) نمایش داده شود.
- «📚 لیست کتاب‌ها»: وضعیت همه کتاب‌ها (پیش‌نویس/فعال/پایان‌یافته).

### گام ۸ — سوالات و پاسخ‌دهی
- ادمین از «❓ تعیین سوالات کتاب» سوالات کتاب را یکی‌یکی وارد می‌کند.
- کاربر از «📝 پاسخ به سوالات» به سوالات کتاب‌هایی که در آن‌ها ثبت‌نام کرده، یکی‌یکی جواب می‌دهد.

## نکات فنی

- دیتابیس sqlite است (فایل `readalong.db`)، بدون نیاز به سرور جداگانه؛ برای گروه‌های بزرگ‌تر به‌راحتی قابل مهاجرت به PostgreSQL است.
- تاریخ‌ها به‌صورت شمسی (جلالی) با کتابخانه `jdatetime` مدیریت می‌شوند و برای زمان‌بندی داخلی به میلادی تبدیل می‌شوند.
- اگر ربات دسترسی ارسال پیام به یک کاربر را نداشته باشد (مثلاً کاربر ربات را بلاک کرده)، خطا لاگ می‌شود ولی ربات کرش نمی‌کند.
- کد کاملاً ماژولار است؛ افزودن قابلیت جدید (مثلاً یادآوری چند بار در روز، یا گزارش هفتگی) فقط نیازمند افزودن یک فایل جدید به `handlers/` است.

## توسعه‌های پیشنهادی بعدی
- افزودن دکمه «ویرایش برنامه» برای کتاب‌های در حال ساخت.
- خروجی اکسل/CSV از گزارش‌ها برای آرشیو.
- امکان پایان‌رسمی کتاب (`status = finished`) و پیام تبریک خودکار در تاپیک گپ.
